# Simple To-Do List in Python

A clean and simple command-line To-Do List application built in Python. This project is designed to practice core programming concepts such as functions, loops, lists, and user input validation.

---

## Features
* **View Tasks:** Display all current tasks in an ordered list.
* **Add Tasks:** Easily add new tasks to your daily list.
* **Delete Tasks:** Remove completed or unwanted tasks by their index number.
* **Input Validation:** Error handling for invalid inputs or out-of-range numbers.
